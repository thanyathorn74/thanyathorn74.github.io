IoT Product · Group project (3 members)

Smart Walking Stick

A smart walking stick for elderly users built on an ESP32. An MPU6050 motion sensor and an FSR402 grip sensor let it count steps, recognise holding, leaning, standing up and walking, and detect real falls from the 3D tilt angle and how long the stick stays down. When a fall happens it beeps, lights an LED and sends an alert to a Wi-Fi app, and it calibrates to each user's grip automatically.

AR Learning App · Group project (3 members)

HemoLens AR

A marker-based AR app that teaches blood-group compatibility, made for people who want to donate blood but don’t know whose blood theirs matches. Scanning one of eight blood-group cards shows a 3D model of that group’s blood cells, along with which groups it can give blood to and receive from, and moving the phone lets you look at the model from every side. Built in Unity with the Vuforia SDK for Android.

Full-Stack Web App

UnNiYam Shop

An online fashion store built with HTML, CSS and vanilla JavaScript on a Node.js and Express REST API with a MySQL database. Customers browse by category, search, collect vouchers and check out with saved addresses and PromptPay, COD or card; sellers add and edit products with up to five images; and admins manage users and approve seller requests. The demo runs entirely in your browser with sample data, so you can try the customer, seller and admin roles.
